# AI 学习助教

这是 Agentic Learning Lab 的贯穿教学项目。

当前阶段：阶段 1，Python 基础。

## 当前能力

- 项目目录已创建。
- 可以通过命令行收集学员名字和学习目标。

## 推荐运行方式

后续课程优先使用 Python 3.13：

```powershell
py -3.13 app/main.py
```

## 目录说明

```text
app/        Python 应用代码
data/       本地学习数据
materials/  学习资料
outputs/    生成的学习计划和总结
tests/      测试代码
```

## 依赖说明

阶段 1.1 暂不安装第三方依赖。

后续课程会逐步把依赖写入 `requirements.txt`。
